## 已完成

- 仿真环境：PX4 SITL + Gazebo（macOS 无窗口）；双相机巡检机型；按种子随机生成的光伏场地（围栏、禁飞区、阵列数量 / 朝向 / 行列、树、缺陷与干扰），附标准答案
- 航线：按阵列偏角计算拍摄点；航段穿过禁飞区时用网格 A* 绕行（含返航）
- 多 Agent 协同（LangGraph）：
  - 调度员、规划员、安全员（确定性规则，拥有否决权）
  - 人工确认（中断与恢复）
  - 飞手、巡检员、报告员、诊断员
  - 多架次换电池；执行中按电量调整
  - 取消、一键返航、异常自动返航
- 飞行前检查（安全员）：飞控自检、传感器超时、仿真速度、位置估计漂移、电脑负载提示；飞行中位置漂移即中止返航；近照未对准时重拍
- 视觉：相机位姿投影、透视校正、编号拼图；初筛与复核的裁决规则（实时与评测共用）
- 排障：飞行日志指标；与已知良好配置对比；对照实验；试飞中的动作超时记为观察结果
- 网页（多页面）：总览、巡检任务、任务详情（平面图与各架次航线、实时遥测、计划确认、协作记录、照片与标注、发现卡片与标准答案对照、HTML 报告）、飞行排障、场景库、用量与成本、评测结果、使用说明
- MCP 服务；离线测试 40 个；CI（后端测试、前端构建）
- 评测：场景录制与离线回放、任务理解与规划、排障（含规则基线）、随机布局回测
- 文档：用户操作手册 docs/user-guide.md；分批计划 docs/roadmap.md
