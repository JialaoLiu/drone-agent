## 已完成

- 仿真环境：PX4 SITL + Gazebo（macOS 无窗口）；双相机巡检机型；按种子随机生成的光伏场地（围栏、禁飞区、阵列数量 / 朝向 / 行列、树、缺陷与干扰），附标准答案
- 航线：按阵列偏角计算拍摄点；航段穿过禁飞区时用网格 A* 绕行（含返航）；可见性图作为可选方法与对比评测
- 真实场地：百度地点检索（SN 签名）→ WGS-84；按真实经纬度生成场景；可选 Mapbox 卫星地面
- 本地初筛分类器（可选，默认关闭）
- 多 Agent 协同（LangGraph）：
  - 调度员、规划员、安全员（确定性规则，拥有否决权）
  - 人工确认（中断与恢复）
  - 飞手、巡检员、报告员、诊断员
  - 多架次换电池；执行中按电量调整
  - 取消、一键返航（飞控层指令优先权：接管后不再发送普通指令）、异常自动返航、起飞半成功也返航
- 飞行前检查（安全员）：飞控自检、传感器超时、仿真速度、位置估计漂移、电脑负载提示、起飞天气（Open-Meteo：风速、阵风、降水、雷暴、能见度；仿真中只提示，WEATHER_ENFORCE=1 时拦截）；飞行中位置漂移即中止返航；近照未对准时重拍
- 视觉：相机位姿投影、透视校正、编号拼图；初筛与复核的裁决规则（实时与评测共用）
- 排障：飞行日志指标；与已知良好配置对比；对照实验；试飞中的动作超时记为观察结果
- 网页（工作台）：左侧下达任务与历史，右侧任务（阶段进度、实时视角、卫星或平面地图、计划确认、协作记录、结论与对照答案、发现、照片、报告）；飞控诊断、场景库、用量与成本、评测结果、设置、使用说明；任务排队；前端按领域分层，场景差异集中在注册表
- MCP 服务；离线测试 91 个；CI（后端测试、前端构建）
- 评测：场景录制与离线回放（24 个场景已录制）、任务理解与规划、排障（含规则基线）、随机布局回测、绕行对比、本地初筛分类器
- 文档：用户操作手册 docs/user-guide.md；方法说明 docs/methods.md；分批计划 docs/roadmap.md
