# 人工验收清单（第三轮：反馈修复 + 应急救援）

更新：2026-10-17。对照负责人第二轮测试文档（`docs/人工测试.docx`）的编号，每条写明改了什么、怎么验证。约 40–60 分钟。发现问题记在最后的记录表。

启动：VS Code 打开 `drone-agent` 文件夹，终端运行 `scripts/start.sh solar_204`，浏览器打开 http://localhost:4790 。停止：`scripts/start.sh stop`。

## A. 之前卡住的问题（1.10、1.11、1.16、1.17）

| 步骤 | 操作 | 应该看到 |
| --- | --- | --- |
| A1 | 飞控诊断页，随便写一个问题，点“开始诊断” | 跳到任务；阶段条依次走“连接飞控 → 基线试飞 → …”，当前动作有扫光动效 |
| A2 | 试飞过程中点“取消任务” | 十几秒内任务变“已取消”，飞机返航；顶部状态回到“仿真就绪”，可以马上下新任务 |
| A3 | 仿真未启动或有任务在执行时打开飞控诊断 | “开始诊断”灰色，按钮下方写明原因 |

## B. 仿真状态与飞行前检查（1.3、1.7、1.8、1.13、1.26、1.29、1.39）

| 步骤 | 操作 | 应该看到 |
| --- | --- | --- |
| B1 | 点顶部仿真状态 | 弹出菜单：重启、停止、更换场景（任何页面都能操作） |
| B2 | 场景库选一个场景点“启动仿真” | 顶部显示“仿真启动中：启动飞控……”和进度条，卡片标“启动中”，右下角提示 |
| B3 | 启动中点“停止” | 立即显示“仿真未启动”，启动按钮可再点；不会全部变灰 |
| B4 | 就绪后点“飞行前检查”标签 | 明细、几秒前检查的、“立即检查”按钮；写明不调用模型、不花钱 |
| B5 | 停止仿真 | 飞行前检查标签立即消失，不再显示过期的结果；状态只显示一个结论 |

## C. 工作台（1.19、1.25、1.32、1.33、1.35、1.1、1.14、1.21、1.34）

| 步骤 | 操作 | 应该看到 |
| --- | --- | --- |
| C1 | 打开工作台 | 左边下达任务与历史任务，右边当前场景预览；真实场地默认显示卫星图 |
| C2 | 点“示例” | 例句按当前场景生成（场地只有 A、B 列时写 A 和 B） |
| C3 | 下一个任务（不勾自动起飞），确认计划 | 右侧阶段条、当前动作扫光；飞机起飞后顶部出现“一键返航”（在地面时不显示） |
| C4 | 执行中再下一个任务 | 按钮变“加入队列”，提示前面还有几个任务；前一个结束后自动开始 |
| C5 | 执行中看“实时视角” | 每秒刷新的机载相机画面，可切广角 / 变焦 |
| C6 | 看地图上的飞机 | 平滑移动与转向，不再一跳一跳 |
| C7 | 任务结束 | 左侧状态自动变“已完成”；右侧一句话结论（达标 / 未达标需复检）；“对照标准答案”逐条列出漏检、误报、类型错，点一行地图定位 |
| C8 | 点“查看报告” | 新样式报告：深色标题、结论行、关键数字、按优先级着色的缺陷卡片 |

## D. 场景库（1.5、1.6、1.9、1.28、1.30、1.38）

| 步骤 | 操作 | 应该看到 |
| --- | --- | --- |
| D1 | 往下翻 | 顶部操作栏一直在 |
| D2 | 地点框输入“千灯湖”，再试“Adelaide Botanic” | 输入时自动出候选；英文地名不再返回国内同名商户 |
| D3 | 选一个地点点“在这里生成场景” | 新场景出现在最前面并自动选中，右下角提示 |
| D4 | 双击卡片或点“预览” | 弹窗显示场地图（可显示标准答案、可直接启动） |
| D5 | 筛选与分页 | 真实场地 / 随机 / 光伏 / 救援筛选；超过 12 个分页 |

## E. 卫星图（1.18、1.20、1.27）

| 步骤 | 操作 | 应该看到 |
| --- | --- | --- |
| E1 | 启动一个真实场地（例如 site_291 千灯湖），看工作台地图 | 默认卫星图，航线、板、围栏叠在影像上，右下角有影像来源 |
| E2 | 切“百度卫星图” | 也能显示（国内备选） |
| E3 | 新生成一个真实场地后起飞，看实时视角 | 仿真地面是该位置的卫星影像，不再是一片绿色 |

## F. 应急救援（新场景）

| 步骤 | 操作 | 应该看到 |
| --- | --- | --- |
| F1 | 场景库左侧选“应急救援”，随机生成并启动 | 卡片缩略图有湖面和地标 |
| F2 | 工作台点“示例”，选第一句，勾自动起飞，下达 | 计划卡片显示搜索中心、方式、半径、高度、拍摄点；阶段条“起飞与搜索 → 发现与确认” |
| F3 | 搜索中看实时视角 | 俯视画面里能看到走动的人、湖面 |
| F4 | 结束后 | 结论（已找到 / 在水中需立即救援 / 没找到）、定位误差、用时；“搜救结果”列出确认照片和看到的每个人；地图上标出每个人 |
| F5 | 输入“帮我找个人” | 调度员追问特征和最后出现的位置 |
